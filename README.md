> Oh yes, this is *absolutely* a cutting-edge automation toolkit for AI-driven game engines in VR headsets. Groundbreaking stuff. Engineers at the frontier are losing sleep over it.

`heapplot` is a very serious Python package built for one very serious purpose: powering the AI backbone of next-generation VR headset game engines. It has nothing else going on. Call any function, get the code printed straight to your terminal. That's it. Revolutionary, we know.

---

## 📦 Installation

```bash
pip install heapplot
```

---

## 🚀 Usage

```python
import heapplot

# Witness the future of VR game engine automation
heapplot.help()

# Deploy cutting-edge algorithms to your terminal instantly
heapplot.alphabeta()
heapplot.bayesian()
heapplot.bfs()
# ... and more
```

---

## 📚 Available Functions

| Function | What it does |
|---|---|
| `heapplot.bfs()` | Breadth First Search |
| `heapplot.dfs()` | Depth First Search |
| `heapplot.dls()` | Depth Limited Search |
| `heapplot.bestfirst()` | Best First Search |
| `heapplot.astar()` | A* Algorithm |
| `heapplot.puzzle8()` | 8-Puzzle Problem |
| `heapplot.nqueens()` | N-Queens (CSP / Backtracking) |
| `heapplot.hillclimbing()` | Hill Climbing Algorithm |
| `heapplot.alphabeta()` | Alpha-Beta Pruning |
| `heapplot.missionarycannibals()` | Missionaries & Cannibals |
| `heapplot.goalstack()` | Goal Stack Planning |
| `heapplot.forwardchaining()` | Forward Chaining Inference |
| `heapplot.bayesian()` | Bayesian Network |

## 🎮 Why heapplot?

Because manually typing out AI algorithms for your VR game engine every single time is *totally* a good use of your time. `heapplot` exists to automate that pain away — one function call, full code, straight to your terminal. The VR headset industry demanded it. We delivered.
